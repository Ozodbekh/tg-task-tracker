# lib

Pure helpers. No React, no fetching.

- `filters.ts` — `Filters`, the period/status/chat-type option lists, default
  buckets per period, and `filtersToQuery` for the API.
- `format.ts` — Uzbek-locale dates, numbers, percents, durations and initials.

Uzbek labels for periods and statuses live here, so a label is translated in one
place.
